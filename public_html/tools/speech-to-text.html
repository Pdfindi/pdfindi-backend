❌ Speech Recognition is not supported in your browser. Please try a modern browser like Chrome or Edge.

Requirements:

🎤 Please allow microphone access to use speech recognition.

To enable microphone:
  1. Click the 🔒 or 🎤 icon in your browser's address bar
  2. Select "Allow" for microphone access
  3. Refresh the page and try again
⚠️ Getting "Network Error" immediately after clicking microphone?

This means the speech recognition service cannot connect to Google's servers. This is a known limitation of the Web Speech API.

Quick Fixes:
  • Check internet: Verify you have a stable internet connection
  • Use Chrome/Edge: This feature only works in Chromium browsers (not Firefox/Safari)
  • Reload page: Press F5 or Ctrl+R and try again
  • Check VPN/Proxy: Disable VPN or proxy if active
  • Try incognito: Open in private/incognito mode (Ctrl+Shift+N)
  • Test connection: Visit google.com to ensure Google services are accessible
  • Clear browser cache: Settings → Privacy → Clear browsing data

Note: The Web Speech API sends audio to Google's cloud servers for processing. If you're behind a strict firewall or corporate network, access may be blocked.
